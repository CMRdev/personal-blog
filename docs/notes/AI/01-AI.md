## 三、插件命令

- ponytail

  | 命令                                       | 说明                                                                |
  | ------------------------------------------ | ------------------------------------------------------------------- |
  | `/ponytail [lite \| full \| ultra \| off]` | 设置强度，或关闭。不带参数时报告当前等级。                          |
  | `/ponytail-review`                         | 审查当前 diff 是否存在过度设计，返回待删除清单。                    |
  | `/ponytail-audit`                          | 审查整个仓库是否存在过度设计，不限于 diff。                         |
  | `/ponytail-debt`                           | 归集 ponytail：把推迟的捷径记入台账，避免"以后再说"变成"永不处理"。 |
  | `/ponytail-gain`                           | 展示基准测试中的量化收益看板（更少代码、更低成本、更快速度）。      |
  | `/ponytail-help`                           | 上述命令的快速参考。                                                |
