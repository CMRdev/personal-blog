# 翻墙

## 1、流程

- 购买VPS，得到：IP 地址，root 用户密码，SSH 端口(默认22)
    - VPS 速度：`香港线路 > 日本线路 > CN2 GIA 线路 > CN2 线路 > 普通线路`
- 安装SSH客户端 `xshell` 或使用终端命令连接`ssh root@remote -p port`
- 安装v2rayN 
    xattr -cr /Applications/v2rayN.app

## 本机修改hosts文件绕过DNS检查

- 用命令行方式查看某个域名的IP：`dig +short github.com`

```bash
# 以管理员身份打开hosts文件
sudo open /etc/hosts  # -a 打开app
# 查询github.com的ip地址
https://www.ipaddress.com/website/
# 刷新DNS缓存
dscacheutil -flushcache
sudo killall -HUP mDNSResponder
```
