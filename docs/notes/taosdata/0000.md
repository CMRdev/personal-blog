- instruction prompt 指令提示
  - 1，首先说明`意图`；
  - 2，然后是针对不同情况的处理方案，每个`方案`有每个方案的实时步骤；

  - 4，最后是提示它当前的`工作目录` (Working Set) 是目前需要处理的文件。
